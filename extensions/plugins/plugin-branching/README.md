# Database Branching

Create instant, writable branches of OpenEverest databases for development,
testing, migration validation, preview environments and AI-agent workflows.
The plugin supports clone and snapshot branches, resets, restore points,
rollback and promotion for supported providers.

## Access

This is a **gated**, commercial extension. It is listed in the hub for
discovery only and cannot be installed from the public catalog. A license and
private registry credentials are required.

- **Request access:** https://solanica.io/contact-us?utm_source=hub-plugin-branching
- **Sales:** sales@solanica.io

After access is granted, Solanica provides the chart reference and installation
instructions.

## Supported providers

- `provider-cloudnative-pg`
- `mariadb`
- `mssql`

Provided and maintained by [Solanica](https://solanica.io).
